  ДЗ

  Работай с тем же классом User

  1. Активные первыми

  Условие:
  Отсортируй пользователей так, чтобы активные были первыми.
  Другие поля не учитывать.

  📌 Ожидаемый результат:
  Сначала все active = true, потом false.

  --------------------------------------------------------------------------

  2. Самые молодые первыми

  Условие:
  Отсортируй пользователей по возрасту по возрастанию.
  Если возраст одинаковый — порядок не важен.

  📌 Подсказка:

  Comparator.comparing

  sorted(Comparator)

  --------------------------------------------------------------------------

  3. Все имена в одну строку

  Условие:
  Получи строку со всеми именами пользователей,
  разделёнными ", ".

  --------------------------------------------------------------------------

  4. Имена активных пользователей

  Условие:
  Получи строку из имён только активных пользователей,
  разделитель — " | ".
